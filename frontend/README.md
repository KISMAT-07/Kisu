# Kisu CMS Admin

React admin panel for the portfolio CMS.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

The default API URL is `http://localhost:8000/api/v1`. Create an admin user with the backend script before signing in.

## Day 5 Scope

- React/Vite admin panel setup.
- Admin login connected to FastAPI JWT authentication.
- Authenticated dashboard shell for CMS content areas.
- Token persistence, current-user loading, logout, and error states.
- CRUD screens for About, Skills, and Projects.
- CRUD screens for Blogs, Testimonials, Experience, and Services.
